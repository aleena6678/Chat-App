# Chat App 💬

![Flutter](https://img.shields.io/badge/Flutter-02569B?style=for-the-badge&logo=flutter&logoColor=white)
![Firebase](https://img.shields.io/badge/Firebase-FFCA28?style=for-the-badge&logo=firebase&logoColor=black)
![Dart](https://img.shields.io/badge/Dart-0175C2?style=for-the-badge&logo=dart&logoColor=white)

A beautiful, real-time chat application built with Flutter and Firebase. This project demonstrates how to build a scalable and responsive messaging app using Firebase Authentication for secure sign-ins and Firebase Realtime Database for seamless real-time messaging.

## ✨ Features

- **User Authentication:** Secure email and password login/registration using Firebase Auth.
- **Real-time Messaging:** Instantly send and receive messages powered by Firebase Realtime Database.
- **State Management:** Efficient and predictable state management using the `provider` package.
- **Clean Architecture:** Well-structured codebase separating UI, models, providers, and services.
- **Timestamps:** Properly formatted message timestamps utilizing the `intl` package.
- **Cross-platform:** Works seamlessly on Android and iOS (and other Flutter-supported platforms).

## 🛠️ Tech Stack & Packages

- **Framework:** [Flutter](https://flutter.dev/)
- **Language:** [Dart](https://dart.dev/)
- **Backend:** [Firebase](https://firebase.google.com/)
- **State Management:** `provider`
- **Other Packages:** 
  - `firebase_core` & `firebase_auth`: Authentication
  - `firebase_database`: Realtime Database
  - `intl`: Date & time formatting
  - `cupertino_icons`: Default iOS-style icons

## 📁 Project Structure

```text
lib/
├── models/             # Data models (User, Message)
├── providers/          # State management (AuthProvider, etc.)
├── screens/            # UI screens (Login, Home, Chat)
├── services/           # Backend services (AuthService, DatabaseService)
├── firebase_options.dart # Firebase configuration
└── main.dart           # Application entry point
```

## 🚀 Getting Started

Follow these steps to get a copy of the project up and running on your local machine.

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) installed
- An IDE like [Android Studio](https://developer.android.com/studio) or [VS Code](https://code.visualstudio.com/)
- A Firebase project set up

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/chat_app.git
   cd chat_app
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Firebase Configuration:**
   - This project uses `firebase_options.dart` which is generated by the [FlutterFire CLI](https://firebase.flutter.dev/docs/cli/).
   - Ensure you configure your own Firebase project by running:
     ```bash
     flutterfire configure
     ```
   - Make sure Authentication (Email/Password) and Realtime Database are enabled in your Firebase Console.

4. **Run the app:**
   ```bash
   flutter run
   ```
